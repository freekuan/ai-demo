商品分组配置项：新旧方案全方位重构对比

直观呈现 5 大核心痛点的升级前与升级后效果

调整前·旧版配置项 (痛点)
  • 无搜索框配置：买家在分组列表里无法快速查找本组商品，流失率高。
  • 排序字段居顶：“排序”字段放在分组名称下方第二行，强行抢占黄金视觉，逻辑本末倒置。
  • 单张静态头图无跳转：仅支持单图上传，不支持轮播与点击跳转至活动或商品。
  • 缺失商品排序规则：无法控制该分组下商品的销量优先、价格高低或新品排列。
  • 右侧预览空白：手机预览只展示头图，下方完全是一片空白，非所见即所得。
调整后·新版设计方案 (推荐)
  • 1. 搜索框默认圆角胶囊：极简配置，支持显隐与占位词，手机端顶部吸顶搜索。
  • 2. 弱化排序字段并下移：移至底部高级属性区，配以辅助说明，聚焦营销主航道。
  • 3. 轮播广告海报+多维跳转：支持 1~5 张轮播、默认速度平滑过渡、跳转商品/其他分组/领券活动/外链。
  • 4. 默认综合推荐商品排序：默认综合推荐（后台权重），并支持销量/上新/价格升降序。
  • 5. 排版支持一行二与一行一：保留大图双列与单列横排，购买按钮支持加号/购物车/选规格/抢购，销量已去除。

商品分组升级需求规格与交互设计规范

版本: v2.2 · 适用端: B端商户工作台 & C端小程序/H5

前后端数据协议模型定义 (TypeScript Interface) 

export interface ProductGroupConfig {
  id: string;
  name: string;                   // 分组名称 (最多20字)
  status: 'NORMAL' | 'DISABLED';  // 正常/禁用
  sort: number;                   // 分组排序 (已弱化下移，越小越靠前)
  
  // 1. 搜索框配置 (默认圆角胶囊)
  showSearch: boolean;            // 是否显示搜索框
  searchPlaceholder: string;      // 搜索提示文案
  
  // 2. 轮播广告配置 (默认3秒轮播，支持跳转)
  banners: Array<{
    id: string;
    imageUrl: string;
    title: string;
    linkType: 'GOODS' | 'GROUP' | 'ACTIVITY' | 'CUSTOM_URL' | 'NONE';
    linkName: string;
    targetValue?: string;
  }>;

  // 3. 商品排序配置 (默认使用综合推荐，前台按此顺序直接排列)
  goodsSortRule: 'DEFAULT' | 'SALES_DESC' | 'NEWEST' | 'PRICE_ASC' | 'PRICE_DESC';

  // 4. 排版样式与购买按钮
  layoutStyle: 'TWO_COLUMNS' | 'ONE_COLUMN'; // 保留：一行2个 vs 一行1个
  cartBtnStyle: 'PLUS_ICON' | 'CART_ICON' | 'SPEC_BTN' | 'BUY_BTN' | 'NONE';
  showOriginPrice: boolean;
  backgroundColor: string;
}
